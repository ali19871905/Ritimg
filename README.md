## 🚀 Getting Started

Python 3 kurulu olmalıdır.

Gerekli paketleri yüklemek için:

```bash
pip install pygame numpy librosa
```

Projelerin her biri kendi klasöründen çalıştırılabilir:

```bash
python ritim4k.py
```

RITIM O için:

```bash
python ritimO.py
```
